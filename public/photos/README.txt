PHOTOS DE REALISATIONS A2BATI

Deposez vos photos dans ce dossier, ou dans un sous-dossier.
Formats pris en charge : JPG, JPEG, PNG, WEBP, AVIF et GIF.

Les photos apparaissent automatiquement dans la galerie apres le prochain
demarrage local (npm start) ou deploiement sur Netlify.
Le site les redimensionne et les allege tout seul : vous pouvez deposer
vos photos telles quelles, meme tres lourdes. Les originaux ne sont pas
publies sur le site, seules les versions allegees le sont.

Astuce : donnez un nom descriptif aux fichiers, par exemple
renovation-cuisine-cestas.jpg. Le nom du fichier sert de legende.
Les noms d'appareil photo (IMG_2904, 10, ...) n'affichent pas de legende.
